This entry is a short, honest little story instead of a loud ad. A woman in a mustard sweater, filming herself in her own kitchen, tells how she tried making something with AI for the very first time: she expected it to be hard, she typed a single sentence, and the result genuinely surprised her. The clip lives on TikTok at the address stored in VIDEO.json, and the small program in this repo is what hands that address to the make.fun grader — it reads the record from the bot folder, checks that the address really points at TikTok, and drops a copy into the output folder.

## Run it

```sh
node main.ts
```
